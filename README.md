# Мастерская открытий

Девять учебных игр для workshop. Капсулы без повторов, коллекция и автоматическое открытие по три игры в день.

## Загрузить на GitHub

1. Распакуйте ZIP.
2. Создайте новый репозиторий в GitHub.
3. Выберите **Add file → Upload files**.
4. Загрузите содержимое папки `workshop-capsules-github`: папки `src`, `scripts`, `worker`, файлы `package.json`, `wrangler.json`, `README.md` и скрытый `.gitignore`.
5. Нажмите **Commit changes**. Загружать сам ZIP вместо файлов не нужно.

В публичном репозитории задания и ответы видны в исходниках независимо от расписания. Если их нужно скрыть до workshop, выберите приватный репозиторий.

## Запуск на компьютере

Нужен Node.js 22 или новее. Откройте терминал в папке проекта:

```sh
npm start
```

Откройте http://127.0.0.1:8877/. Для остановки нажмите Ctrl+C. Внешних npm-зависимостей у приложения нет.

```sh
npm test
npm run build
```

Команды проверяют игры и расписание, затем собирают самостоятельный файл `worker/index.js` с интерфейсом и изображениями.

## Публикация

GitHub хранит исходники. **GitHub Pages не выполняет серверный код**, который нужен для проверки времени открытия игр. Используйте Cloudflare Workers или совместимый хостинг Worker ESM.

Для Cloudflare Workers в архиве есть `wrangler.json`. Через официальный CLI Wrangler:

```sh
npx wrangler login
npx wrangler deploy
```

Потребуется ваш аккаунт Cloudflare. Будет создан отдельный адрес сайта. Архив сам ничего не публикует, существующий сайт ChatGPT Sites не изменяется.

## Расписание — Москва, UTC+3

- 13 октября 2026, 13:00: счёт до 10, звуки и буквы, чтение и письмо.
- 14 октября 2026, 13:00: вычисления до 100, орфография, состав слова.
- 15 октября 2026, 13:00: умножение и деление, величины, окончания существительных.

Даты фиксированы: публикация не сдвигает расписание. После 15 октября в 13:00 доступны все игры. Для следующего workshop измените `RELEASES` в `src/games.js`, даты и подписи в `src/page.html`, затем соберите и опубликуйте сайт.

Доступ проверяет сервер, а не часы устройства. Страница автоматически обновляет доступ. Переменная `WORKSHOP_QA_TIME` предназначена исключительно для локальных проверок через `scripts/dev.mjs`. Опубликованный Worker всегда использует настоящее время.

## Файлы

- `src/games.js` — задания, ответы, объяснения, даты.
- `src/app.js` — автомат, коллекция и игровые взаимодействия.
- `src/page.html`, `src/style.css` — интерфейс.
- `src/server.js` — маршруты и проверка времени.
- `src/hero-assets.json` — изображения в base64.
- `scripts/compose.mjs` — сборка.
- `scripts/test*.mjs` — проверки всех 54 заданий и границ открытия.
- `worker/index.js` — собранный сервер.

Коллекция сохраняется в localStorage конкретного браузера. Между устройствами не синхронизируется, при очистке данных браузера сбрасывается. Озвучивание требует русского голоса в браузере.

В архив не включены Git-история, служебная привязка ChatGPT Sites, ключи или пароли.
